# VOLTZ for Horizon

The mods of the classic **Voltz** modpack, remade for [Horizon](https://github.com/horizon-rust/horizon)
(Minecraft: Java Edition 26.3 rewritten in Rust): power networks, machines, ore processing, explosives and missiles,
storage networks, pipes and quarries. All code is new and written for Horizon; see [CREDITS.md](CREDITS.md) for the
original mods, their authors and licences. Not affiliated with Mojang, Microsoft, Horizon or the original authors.

## What's in it

| From | What |
|---|---|
| Voltz power | copper wire, coal / geothermal / solar generators, battery box, energy storage units, electric furnace, crusher, compressor, extractor |
| Mekanism | enrichment chamber, crusher, energized smelter, osmium compressor, metallurgic infuser, heat + wind generators, energy cubes, osmium ore, alloys, circuits, tools and armor |
| ICBM Classic | 16 explosive blocks armed by redstone (condensed, incendiary, shrapnel, breaching, nuclear, EMP, endothermic, anvil rain...) |
| Ender IO | alloy smelter, SAG mill, slice'n'splice, soul binder, stirling generator, capacitor banks, energy conduits, dark steel gear |
| Tinkers' Construct | nether cobalt + ardite, smeltery, tool parts and tools |
| BuildCraft | wooden / cobblestone / stone / gold item pipes, quarry |
| Applied Energistics 2 | ME controller, drives + storage cells, terminal (a chest menu of everything stored), cable, import bus |
| Iron Chests | copper, iron, gold, diamond, crystal, obsidian chests |

Two parts, both needed:

- `content/voltz` — the **content mod** (`.hmod`): blocks, items, recipes, loot, models, textures (generated by
  `tools/gen_content.py`, then `tools/public_filter.py`).
- `native/voltz_core` — the **native mod** (`.hnmod`, a [horizon-mixins](https://github.com/horizon-rust/horizon-mixins)
  bundle): the energy network, machines, explosives, ore generation, AE2 network, pipes and quarry. Its logic is in
  `engine/` (plain Rust, unit-tested) and folded into `voltz_engine.rs` by `tools/gen_engine_module.py`.

## Build

```sh
python3 tools/gen_content.py && python3 tools/public_filter.py     # content/voltz
python3 tools/gen_engine_module.py                                  # native/voltz_core/voltz_engine.rs
cargo test --manifest-path native/voltz_core/engine/Cargo.toml       # engine tests
cargo horizon-mod build content/voltz                                # voltz.hmod
```

Players: put `content/voltz` in `horizon-mods/` and `native/voltz_core` in `horizon-native-mods/`, then build with
the Horizon launcher (`horizon-launcher native-build`).

## Playing

- Power: generators push energy into copper wire (or conduits); machines, batteries and cubes on the wire share it.
- Every machine opens a furnace menu: input on top, fuel or second ingredient in the middle, output on the right; the
  flame shows stored energy, the arrow progress.
- Explosives go off 4 seconds after a redstone signal. The ME terminal opens with a right click.
- New ores (osmium, cobalt, ardite) appear in chunks generated after the mod is installed.
