# Credits

VOLTZ for Horizon is a fan remake of the **Voltz** modpack's mods for [Horizon](https://github.com/horizon-rust/horizon)
(Minecraft: Java Edition 26.3 rewritten in Rust). **Every line of code here is new**, written for Horizon: nothing
was copied or decompiled from the original mods. The ideas, names and gameplay these remakes follow belong to the
original mods' authors, credited below. Please support the originals.

Mods marked *inspired* here are not ports: those parts are our own designs that follow the same kinds of gameplay
(machines, power, explosives) under generic names. The public build uses only textures drawn for this project (`tools/gen_content.py`). It never includes art from
the original mods. `tools/import_textures.py` can copy a player's *own* installed jars' textures into their *local*
build for personal use; those textures are never committed or published.
